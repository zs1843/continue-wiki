## 判断“完整”的标准

模型内部怎样计算 → 参数怎样训练与适配 → 推理怎样运行、成本从哪里来 → 资料怎样进入系统 → 系统怎样编排行动与记忆 → 哪些动作允许执行 → 怎样证明它有效 → 怎样上线与治理

这条链现在每一段都有入门笔记，但“入门”不等于“讲透”。

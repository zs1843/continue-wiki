# AI 知识体系完整性审计

2026-11-20 盘点 61 篇公开笔记。逐层列出“应该能回答的问题”，对照现有章节判断：能回答、只答一半、答不了；半与不能的项标注去向（加深、补齐或明确不做）。判断依据是各篇的实际章节与 [来源索引](sources.md) 记录的读取范围，不凭印象补写。

使用方式：先看某一层的问题清单，能答的直接跳到对应笔记；标“半”和“不能”的，就是下一批要补的地方。

## 汇总

- **能回答**：主干链路每层都有入口，概念定义、机制与边界基本成立。
- **只答一半**：集中在参数细节、工程流程、统计度量、组织落地四类。
- **答不了**：集中在位置编码与长上下文、推理引擎选型、排序指标与统计、文档理解与结构化检索、视频与 GUI、组织与商业、供应链与合规。

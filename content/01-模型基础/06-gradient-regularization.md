**梯度** 告诉训练算法参数该往哪个方向调；**过拟合** 是模型把训练集记住了，却没学到可迁移的规律；**正则化** 则通过限制模型复杂度来换更好的泛化。三者一起决定“训练到底在优化什么”。

## 梯度由反向传播计算

训练时，前向传播按输入到输出的顺序计算并保存中间变量；反向传播按相反顺序，用链式法则计算每个参数对损失的梯度。[1]

对复合函数 `Z = g(Y)`、`Y = f(X)`，链式法则写成：

```text
∂Z/∂X = prod(∂Z/∂Y, ∂Y/∂X)
```

其中 `prod` 表示按张量形状做必要的转置、换位后再相乘。对参数来说，反向传播会沿计算图逐层累积梯度，最后得到每个权重矩阵的更新方向。[1]

## 训练比推理更占显存

反向传播需要复用前向传播保存的中间值，因此这些值必须保留到反向计算结束。中间值的大小大致与网络层数和批大小成正比；层越深、批越大，越容易显存不足。[1]

这也解释了一个常见现象：同一模型推理能跑，训练却跑不动。训练多出来的是激活值与梯度，不只是模型权重。

## 过拟合是训练误差与真实误差分离

训练集上的准确率高，不能说明模型学到了规律。D2L 提醒：当每个输入都独特时，模型甚至可以靠记住训练集在第一个 epoch 达到完美准确率，但遇到新样本仍然只能随机猜。[2]

测试集的作用是估计总体误差。若测试集是从总体中独立抽取的 n 个样本，测试误差是总体误差的估计量；中心极限定理给出估计的标准差约为 `σ/√n`，而 0/1 损失的方差最大为 0.25，因此标准差不超过 `√(0.25/n)`。[2]

文中给出几个具体换算：想让一个标准差对应 ±0.01，需要约 2500 个样本；想以 95% 置信度落在 ±0.01，需要约 10000 个；用不依赖渐近分布的 Hoeffding 界（一种有限样本误差上界）更保守，约需 15000 个。[2] 这些数字说明：小数点后两位的“提升”，在小测试集上可能只是噪声。

## 测试集重复使用会失效

测试集只有在“模型没有接触过它”时才成立。如果用同一个测试集比较多个模型，就会遇到多重比较问题：比较的模型越多，至少一个模型碰巧表现好的概率越大；如果后续模型是根据前一个模型在测试集上的表现改进的，测试集信息已经泄漏，D2L 称之为自适应过拟合。[2]

文中的实践建议是：保留真正的测试集，尽量少看；报告置信区间时考虑多重检验；数据少、风险高时更保守；长期做基准时保留多个测试集，用过的降级为验证集。[2]

## 正则化限制参数规模

权重衰减（L2 正则）在损失上加一项 `(λ/2)·‖w‖²`：

```text
目标函数 = 原损失 + (λ/2) · ‖w‖²
```

λ 为 0 时退回原损失；λ 越大，对大权重的惩罚越强。在 minibatch 随机梯度下降里，这一项会让每一步先把权重按 `(1 - ηλ)` 缩小，再减去梯度项，所以叫“权重衰减”。[3]

D2L 的合成例子把问题设成 200 维输入、只有 20 个训练样本：不加正则时训练误差下降但验证误差不降；加上较大的权重衰减后，训练误差上升、验证误差反而下降。[3] 这个例子说明正则化不是让训练更好看，而是换取泛化。

L1 正则（`Σ|w_i|`）与 L2 的倾向不同：L2 倾向于把权重分散到更多特征上，L1 会把部分权重压到 0，因而可用于特征选择。[3] 偏置项通常不做正则，具体取决于实现。[3]

## 边界

- 正则化不能替代数据；它只是在给定数据下限制模型复杂度。
- λ 是超参数，要在验证集上选，而不是在测试集上调。
- 训练目标、困惑度与任务效果不是一回事，参见[交叉熵与困惑度](/notes/cross-entropy-and-perplexity/)。
- 微调时还会叠加 LoRA 等参数约束，见[LoRA 与 QLoRA](/notes/lora-peft/)；这些约束与权重衰减不是同一层机制。

**交叉熵** 衡量“模型给真实标签分配的概率”有多低：概率越接近 1，损失越接近 0；概率越接近 0，损失越大。**困惑度** 是它的指数形式，用来描述语言模型在每一步平均面对多少个“差不多的选择”。

## 交叉熵衡量预测分布与真实标签的差距

softmax 回归把每个类别的分数转成概率后，用负对数似然（negative log-likelihood，对预测概率取对数再取负）作为损失。对 one-hot 标签 y（只有一个位置为 1、其余为 0 的向量）和预测概率 ŷ：

```text
l(y, ŷ) = - Σ_j  y_j · log(ŷ_j)
```

因为 one-hot 向量只有一个位置是 1，求和只剩真实类别那一项，所以损失就是 `-log(ŷ_真实类别)`。[1]

这个损失下界是 0，只有预测真实类别概率为 1 时才取到；而 softmax 要把概率推到 1，需要对应分数趋于无穷，因此有限参数下损失不会正好为 0。若模型给真实类别概率 0，损失趋于无穷。[1]

## softmax 把分数变成概率

模型先算出每个类别的分数（logits）`o_j`，再用 softmax 归一化：

```text
ŷ_i = exp(o_i) / Σ_j exp(o_j)
```

指数保证非负，除以总和保证加起来为 1；因为指数函数单调，分数最大的类别仍然是概率最大的类别。softmax 与交叉熵组合后，对分数的导数有一个很简洁的形式：[1]

```text
∂l / ∂o_j = ŷ_j - y_j
```

也就是说，梯度就是“预测概率减去真实标签”。预测偏高就往下压，预测偏低就往上推。

## 困惑度是平均交叉熵的指数

语言模型每一步预测下一个 token。对长度为 n 的序列，平均交叉熵是：

```text
平均交叉熵 = (1/n) · Σ_t  -log P(x_t | x_{t-1}, ..., x_1)
困惑度     = exp(平均交叉熵)
```

D2L 给出三种参照：模型总能把真实 token 的概率预测为 1 时，困惑度为 1；总预测为 0 时，困惑度为无穷大；如果模型对所有词给出均匀分布，困惑度等于词表大小。[2]

因此困惑度可以理解为“每一步平均在多少个等可能选项里选”。数值越低，模型对文本的预测越确定；但它衡量的是对语料的拟合，不直接等于回答质量。

## 示例与边界

假设词表只有四个 token，真实下一个 token 是“学习”，模型给出概率 0.5：

- 交叉熵为 `-log(0.5) ≈ 0.693` 自然对数单位。
- 若整段序列每一步都如此，平均交叉熵约 0.693，困惑度约 `e^0.693 ≈ 2`，相当于每一步在两个等可能选项里选。

这个例子是自拟的，用来说明换算关系，不是实验结果。

边界：

- 困惑度以词表大小为基准；不同分词器的词表不同，数值不能直接横向比较。这是由定义推出的使用限制，具体比较仍要看评测设置。
- 困惑度低只说明模型更会预测语料，不代表更会遵循指令或回答正确，后者要用[评测集与评分器](/notes/evaluation-sets/)衡量。
- 交叉熵是训练目标，困惑度是评估口径；训练时还会加入正则、掩码等处理，参见[训练与推理](/notes/training-and-inference/)。

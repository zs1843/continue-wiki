# 思维导图

站点入口为 `/mindmaps/`，左侧「思维导图」目录可打开知识总览或主题导图，支持缩放、拖动、展开／收起分支和全屏查看。点击节点文字可打开对应笔记；带章节定位的节点直接跳到正文位置。

本目录保存可追踪、可重新生成的 Markdown 导图：

- `knowledge.md`：全部已公开笔记的知识总览。
- `topic-*.md`：按笔记顶层目录生成的主题导图，标题记录在各文件的 frontmatter 中。文件 ID 根据目录确定，笔记链接使用稳定 slug。

每篇笔记的 `mindmap` 字段记录简短知识点，节点从这里生成。未设置该字段的公开笔记仍会作为概念节点进入导图。草稿不会进入总览、分类导图或前端数据。

```yaml
mindmap:
  - label: "一句简短的关键知识点"
  - label: "可定位到某个章节的知识点"
    heading: "章节的实际锚点"
```

`heading` 填页面中标题链接的锚点，不带 `#`；中文标题也可以使用。每篇最多 8 个知识点，通常保留 1–4 个即可。导图不是正文的替代品，详细定义和出处仍保留在笔记中。

```sh
npm run maps   # 更新本目录的生成文件
npm run check  # 检查知识点和章节，并确认导图已同步
npm run build  # 自动更新导图，再检查和构建整个站点
```

不直接修改标记为生成的 Markdown。生成器会更新和清理自己生成的文件，保留其他手写文件；手写文件不自动作为站点导图发布。构建后的交互页面位于 `dist/mindmaps/`，可以随现有静态站点发布。

渲染使用 [Markmap](https://markmap.js.org/docs/packages/view) 1.1.1，依赖打包在本地静态资源中。布局提供知识点的层级总览，跨笔记的具体关系仍通过正文链接表达。
